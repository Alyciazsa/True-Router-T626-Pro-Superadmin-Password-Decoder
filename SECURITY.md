
    # Security Policy

    ## 🔒 Privacy & Offline Guarantee
    All decoding and password extraction routines in this repository execute **100% locally and offline** on your machine (via PowerShell, Python, or the client-side WebAssembly
    ￹decoder).

    - **No Data Collection:** Your router configuration backup (`romfile.cfg` / `bfwcfg.dt`), serial numbers, MAC addresses, and passwords are never transmitted to any external
    ￹server or third party.
    - **Auditable:** All source code is completely open-source and unminified for public audit.

    ## 🛡️ Reporting a Vulnerability
    If you discover a security vulnerability or sensitive data exposure issue within this project, please report it privately:
    - Open a **[Private Vulnerability Report](https://github.com/Alyciazsa/True-Router-T626-Pro-Superadmin-Password-Decoder/security/advisories/new)** via GitHub.
    - Or contact the maintainer directly via GitHub profile.
